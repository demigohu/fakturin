## Cancelled (target not reached)

Every deposit is returned 1:1. Nobody pays anything except gas.

## Token flows by function

| Function | Token movements |
| --- | --- |
| `deposit(a, r)` | lender → vault `a`; vault mints `a` shares to `r` |
| last `deposit` | additionally vault → seller `advance` |
| `repay()` | payer → vault `N`; vault → seller `holdback`; vault → treasury `fee` |
| `redeem(s, r, o)` | vault burns `s` shares of `o`; vault → `r` its share of the balance |
| `markDefault()`, `cancelFunding()` | none (only the state changes) |
