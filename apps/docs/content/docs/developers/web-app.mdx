title: Web app configuration
description: Environment variables of apps/web and what each one switches.
---

The web app reads `apps/web/.env` (gitignored). Start from `apps/web/.env.example`.

| Variable | Required | Description |
| --- | --- | --- |
| `NEXT_PUBLIC_REOWN_PROJECT_ID` | yes | Reown (WalletConnect) project ID for AppKit |
| `NEXT_PUBLIC_ARBITRUM_SEPOLIA_RPC_URL` | yes | RPC used by the browser and server routes |
| `NEXT_PUBLIC_MOCK_IDRX_ADDRESS` | yes | MockIDRX |
| `NEXT_PUBLIC_FAKTUR_NFT_ADDRESS` | yes | FakturNFT |
| `NEXT_PUBLIC_FAKTUR_VAULT_FACTORY_ADDRESS` | yes | FakturVaultFactory |
| `NEXT_PUBLIC_FAKTUR_REGISTRY_ADDRESS` | yes | FakturRegistry |
| `NEXT_PUBLIC_FAKTUR_RECEIVER_ADDRESS` | yes | FakturVerifierReceiver |
| `NEXT_PUBLIC_FAKTUR_KEEPER_ADDRESS` | yes | FakturKeeper |
| `NEXT_PUBLIC_FAKTUR_RENDERER_ADDRESS` | yes | FakturRenderer |
| `NEXT_PUBLIC_ACE_IDENTITY_REGISTRY_ADDRESS` | yes | ACE IdentityRegistry |
| `NEXT_PUBLIC_ACE_CREDENTIAL_REGISTRY_ADDRESS` | yes | ACE CredentialRegistry |
| `NEXT_PUBLIC_DEPLOY_BLOCK` | yes | L2 block to start event scans from |
| `NEXT_PUBLIC_SITE_URL` | no | Public URL, for Open Graph links |
| `NEXT_PUBLIC_VERIFIER` | no | `relayer` (default) or `cre`. See [modes](/docs/architecture/deployment#two-automation-modes). |
| `VERIFIER_PRIVATE_KEY` | relayer mode, identity | **Server only.** Holds `VERIFIER_ROLE`, is the ACE issuer, pays keeper gas. |

<Callout type="error" title="Never prefix a key with NEXT_PUBLIC_">
  Anything starting with `NEXT_PUBLIC_` is shipped to the browser. `VERIFIER_PRIVATE_KEY` must stay server-only.
</Callout>

## Docs site

`apps/docs` reads `NEXT_PUBLIC_APP_URL` (link to the app, default `http://localhost:3000`) and `NEXT_PUBLIC_DOCS_URL` (its own public URL, for metadata). Content is MDX in `apps/docs/content/docs`; diagrams use the `<Mermaid chart={...} />` component.
